## OS Command Injection

Добавить новый эндпоинт, который выполняет системную команду с пользовательским вводом — например, "конвертировать загруженное изображение" через `ProcessBuilder/Runtime.exec()`, вызывающий `convert` (ImageMagick) или `ffmpeg`, где имя файла подставляется в команду.

Теория:
- [OS Command Injection Defense](https://cheatsheetseries.owasp.org/cheatsheets/OS_Command_Injection_Defense_Cheat_Sheet.html)
- [PortSwigger — OS command injection](https://portswigger.net/web-security/os-command-injection)

Демо-приложение представляет из себя простой ретранслятор ping - принимает в качестве аргумента из HTTP-запроса адрес хоста.
Первый эндпоинт приложения парсит host как единую переменную из тела запроса - потенциальная возможность через ; передать дополнительные команды в консоль и исполнить любое действие, не требующее sudo-прав (в качестве примера вывод содержимого /etc/os-release в ответ запроса (информация для злоумышленника малополезная, но для демонстрации возможности удаленного исполнения команды подойдет))

Второй эндпоинт парсит host как отдельное значение и верифицирует как ipv4-адрес. Если получили что-то другое - кидаем ошибку 400
В коде реализовано методами isValidHost() и другим принципом формирования команды для запуска:

Уязвимый: 
```cpp
std::string command = "ping -c 3 " + host;
```
Защищенный: 
```cpp
std::string command = "ping -c 3 '" + host + "'";
```
Запуск тестировался на Debian 12, работоспособность на остальных ОС не тестировалась
Команды:
``` bash
chmod +x start.sh attack.sh
./start.sh
./attack.sh
```
Первый скрипт сетапит docker-окружение, второй - запускает саму демонстрацию атаки
